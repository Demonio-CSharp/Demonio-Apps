Privacy Policy

Application: PerfectPlayFx | Package: com.demonioapps.perfectplayfx

Developer: DemonioApps | Effective Date: October 2026

1. Summary and Core Privacy Principles

Zero Personal Data Collection: PerfectPlayFx does NOT collect, store on remote servers, transmit, or share any Personally Identifiable Information (PII) from users.

This Privacy Policy applies to the mobile application PerfectPlayFx ("the Application"), developed by DemonioApps and distributed via Google Play Store.

The Application is a real-time retro synthesizer, audio player, and interactive holographic visualizer (CyberEye Live Wallpaper). All audio synthesis and shader rendering execute 100% locally on your device without requiring or establishing connections to any proprietary cloud servers.

2. Information Collection and Use

  • No User Accounts: We do not require or offer user registration. No names, email addresses, phone numbers, or passwords are ever collected.
  • No Access to Sensitive Data: The Application does not access your contacts, calendar, camera, microphone, photo library, or personal files.
  • No Geolocation: We do not track, collect, or store geographic location data (neither GPS nor network-based).

3. Device Information and Offline License Verification

To allow users who purchase the Pro Unlock version to use all features completely offline (airplane mode, no internet connection), the Application performs local verification:

  • Device Identifier (ANDROID_ID): Processed strictly in volatile memory (RAM) via native C++ code to compute a 64-bit cryptographic ARX-MAC license token tied to the verified Google Play purchase signature.
  • Local Isolation: This identifier is NEVER transmitted to external servers, never stored in cloud databases, and never used for tracking, profiling, or advertising.

4. Declared Android System Permissions

The Application declares only the necessary system permissions to operate its media and visualizer services:

Permission Purpose
FOREGROUND_SERVICE
FOREGROUND_SERVICE_MEDIA_PLAYBACK		 Allows continuous background audio playback when the app is minimized or the screen is turned off.
POST_NOTIFICATIONS Used on Android 13+ strictly to show the system media playback notification card with transport controls (Play, Pause, Stop, Track title). No marketing notifications are sent.
com.android.vending.BILLING Enables Google Play In-App Billing for the optional one-time Pro Unlock purchase.
BIND_WALLPAPER Required by Android framework if the user chooses to set the CyberEye interactive visualizer as their Live Wallpaper.

5. Third-Party Services

The Application relies solely on official Google Play platform services:

  • Google Play In-App Billing (Google LLC): All purchases are processed directly and securely by Google. The developer does not receive, collect, or store any payment card or financial details. Governed by the Google Privacy Policy.
  • Crash & Diagnostic Reports (Google Play Console): If enabled in device OS settings, Google may provide anonymized stack traces and hardware specs to assist in debugging crashes.
  • Zero Advertising SDKs: The Application contains no ads (no Google AdMob, Unity Ads, etc.).
  • Zero Analytics Trackers: The Application contains no third-party telemetry tools (no Firebase Analytics, Facebook SDK, AppsFlyer, etc.).

6. Children's Privacy (COPPA / GDPR-K)

The Application is a specialized audio synthesizer and visualizer for general audiences. It is not directed at children under the age of 13. We do not knowingly collect personal information from children.

7. Security and User Rights

All internal assets are protected by cryptographic streaming algorithms. System auto-backups are disabled (android:allowBackup="false") to prevent data extraction. Because no personal data is stored on remote servers, user rights (GDPR, CCPA) regarding data deletion are satisfied by simply uninstalling the application.
